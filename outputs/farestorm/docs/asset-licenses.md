# Assets and attribution

## Original project content

- Galeport road plan, destination identities, passenger names/lines, taxi shapes, turbine concept and vehicle colors: created for this project.
- Procedural city, vehicles, props, markers and effects: project source code. No external vehicle or city model pack is bundled.
- `src/assets/farestorm-keyart.png`: original image generated for this project using the built-in image generation tool. Its brief used a coastal Galeport scene, cream/coral architecture, cobalt water and an original storm cab with a roof turbine. No reference game screenshots or licensed characters were supplied.
- `public/icon.svg`: original geometric storm-cab mark created in project source.
- Music, engine, tires, horn, collision and event cues: original procedural Web Audio synthesis in `src/game/audio.ts`. No recorded song or licensed soundtrack is bundled.
- Passenger text is original. Recorded voice performances are not bundled.
