# Asset provenance

All names, characters, dialogue, missions, vehicle names, district layout and interface composition are original to this implementation. No extracted commercial-game map, logo, character, texture, music or sound is used.

The district façades, palm fronds, road meshes, sky shader, beveled coachwork and tire-force foundation adapt original source authored for the approved sibling Farestorm project in this workspace. Its files were not changed. Meridian supplies a separate city, character rigs, motorcycles, interiors, missions, pedestrians, weapon/evidence systems, presentation and score.

The renderer creates geometry procedurally. It does not fetch runtime images or model assets. The icon and map are locally authored SVG geometry. Audio is locally synthesized with Web Audio; the melodic pattern and effects are original. There is no AI-generated bitmap artwork in this game.

Third-party runtime packages are Babylon.js (`@babylonjs/core`), Rapier (`@dimforge/rapier3d-compat`), React/React DOM, Phosphor icons, and the locally bundled Barlow/Barlow Condensed font packages. Package versions are pinned by `package-lock.json`; their original license files remain in their packages. Consult those licenses before redistributing a modified dependency bundle.

Screenshots in the project are captured from this game, not illustrations presented as gameplay. `meridian-first-shift-result.png` records the browser-completed first delivery; final gameplay/title screenshots document the shipped visual build.
