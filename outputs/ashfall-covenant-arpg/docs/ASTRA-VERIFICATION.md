## Save and architecture notes

Simulation remains the authority for damage, resources, ranks, attributes, loot and quests. `presentation.ts` contains procedural geometry and articulation; `runtime.ts` consumes state/events and owns camera, picking, DOM damage labels, minimap, sound and input. Static scenery is merged by material. The optional development-only `__ashfallQA` bridge exposes copied inspection and ordinary intents; production dead-code elimination removes it.

The IndexedDB schema remains backward compatible (version 1). Hero attribute allocation is an optional field defaulting to zero for old saves. A missing starter weapon is repaired without discarding inventory. Completed boss states are reconstructed from quest progression. Save records have an FNV checksum and a previous valid backup; save data is cloned before asynchronous writes. Checksum is corruption detection, not tamper resistance or an online authority.

All newly added geometry and textures are generated by project source; no externally licensed model or audio pack was added. Existing generated title art remains under `src/assets/`.
