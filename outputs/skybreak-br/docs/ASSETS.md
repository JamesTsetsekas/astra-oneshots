# Original assets and provenance

## In-game content

All terrain, settlement architecture, trees, windmills, clouds, scavenger bodies/limbs, wing-sails, weapons, utility models, sky shader, icons specific to equipment, and synthesized game sounds were authored in this project. They use programmatic geometry or WebAudio. No existing game's character, map, weapon mesh, texture, branding, sound, or logo was copied.

Barlow and Barlow Condensed are packaged locally through Fontsource (SIL Open Font License). UI action icons are Phosphor Icons (MIT). React (MIT), Babylon.js (Apache-2.0), and Rapier (Apache-2.0) retain their dependency licenses in the installed packages.
